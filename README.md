# human-alpha-amylase-alignment
Human alpha-amylase sequence alignment as a Bioinformatics assignment
This project presents a bioinformatics assignment focused on the identification and sequence comparison of human alpha-amylase with three similar eukaryotic proteins.

Workflow

1. Identification of human alpha-amylase using NCBI
2. Identification of three similar eukaryotic proteins
3. Collection and comparison of protein information
4. Sequence alignment and analysis

Report

The complete assignment report, including the collected protein information, alignment results, screenshots, and explanations, is available in the PDF file.
